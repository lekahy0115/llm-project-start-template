# 공개 포트폴리오와 재현 정보

GitHub를 열람하는 사람이 프로젝트의 목적·구현·평가·기여도를 확인할 수 있도록 아래 정보를 채웁니다.

## README에 제시할 항목

1. 프로젝트 문제 정의, 입력·출력 예시
2. 전체 데이터 흐름과 Colab `.ipynb` 파일의 역할
3. 사용한 모델·데이터셋의 출처와 라이선스
4. 실험 설정 및 정량/정성 평가 결과 (`outputs/`, `assets/`에 작은 자료 저장)
5. 팀원별 담당 기능과 주요 PR·Commit 링크
6. 실제 실행 환경(GPU·라이브러리 버전)과 재현 순서
7. ngrok 웹 시연 방법과 서비스 화면 캡처

## Drive에만 있는 대용량 파일

`DATA_MODEL_REGISTRY.md`에 파일 버전·경로·크기·해시·Git Commit을 연결합니다. 별도의 공개 다운로드 경로가 없다면 **면접관이 Google Drive 파일에 직접 접근할 수 없다는 사실**을 명시합니다. 공개할 수 있는 샘플 데이터와 기본 모델 다운로드 경로를 이용한 부분 재현 절차를 설명할 수 있습니다.

## 공개 전 점검

- `.ipynb` 셀 출력에 토큰·API 키·개인정보가 남아 있지 않은지 확인
- `.gitignore` 외에 Git 이력에 비밀정보가 이미 포함된 적은 없는지 검토
- 데이터·모델 라이선스에 위배되는 공개 파일이 없는지 확인
- 이미지에 계정·이메일·접근 링크 등 비공개 정보가 없는지 확인
- 완료되지 않은 기능을 구현되었다고 소개하지 않음

현재 구현 기술·측정 결과는 확정되지 않았으므로 수치나 기능은 임의로 기입하지 않습니다.
