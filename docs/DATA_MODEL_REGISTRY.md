# 데이터·모델 버전 등록표

Google Drive에 실제로 저장한 대용량 파일의 버전과 GitHub Commit을 연결하여 관리합니다. **아직 등록된 데이터·모델은 없습니다.** 등록 시 아래 빈 표에 실제 값만 기입합니다.

| 종류 | 이름 | 버전 | Drive 상대 경로 (`RENAME_ME_SHARED_DATA/` 기준) | 출처/라이선스 | Git Commit | SHA-256 또는 크기 | 용도 |
|---|---|---|---|---|---|---|---|
| — | — | — | — | — | — | — | — |

## 기록 방법

- **종류:** 원본 데이터 / 전처리 데이터 / 기본 모델 / 파인튜닝 가중치 / 체크포인트 / 결과물
- **버전:** 원본을 수정하지 않고 새 폴더로 저장할 때 증가 (`v001`, `v002` 등)
- **Drive 상대 경로:** 예 `datasets/raw/v001/example.csv` (실제 파일이 생성된 이후 기록)
- **출처/라이선스:** 공개 다운로드 주소와 이용 조건, 자체 생성 여부
- **Git Commit:** 해당 파일을 읽거나 생성한 노트북의 Commit 해시
- **SHA-256 또는 크기:** 필요하면 파일 무결성 검증에 사용
- **용도:** 해당 실험·평가·시연에서 어떻게 사용했는지 한 줄 기록

비공개 Drive 공유 링크, 접근 토큰 또는 개인정보는 Public 저장소의 표에 포함하지 않습니다.
